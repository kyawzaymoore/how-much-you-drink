# 🍺 How Much You Drink

A tiny beer counter web app built with plain HTML and JavaScript.

- Add people by name
- Tap **+1 🍺** each time someone orders or drinks a beer
- Tap **−** to undo a mistake, **✕** to remove a person
- See everyone's count, a leaderboard (🥇🥈🥉) and the group total
- Counts are saved in your browser (localStorage), so they survive a page refresh

Live site: https://kyawzaymoore.github.io/how-much-you-drink/

Run locally: just open `index.html` in a browser.
